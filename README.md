# Neverwin_Lua — Neverwin CS2 Lua 脚本合集

运行于 Neverwin 平台的 CS2 Lua 脚本仓库。作者 **Awa Subaru**（yry4399）。

## 脚本

### Fake misc.lua — 主菜单伪造套件（自主开发）

完全自主开发，通过 client.dll 特征码定位 + 内存写入实现，**仅自己可见**，不影响真实账户数据：

- **虚假等级**：1-40 级 + 经验值（资料卡军衔图标、服役勋章按钮同步变化）
- **虚假优先分数**：0-99999 分数 + 胜场（0-9999）
- **虚假搭档段位**：白银 I ~ 全球精英 18 段 + 胜场（0-9999）
- **虚假冷却**：4 种时长 × 23 种冷却原因（被踢/中途退出/作弊定罪/GSLT 违规/VACNet 等，横幅显示对应原因文本）
- **虚假封禁**：VAC 封禁 / 游戏封禁横幅
- **虚假未封禁**：一键消除真实封禁/冷却的图标显示（仅本地视觉）
- **虚假延迟**：本地记分板假 ping（0-999999ms）
- **状态组**：Allow Insecure 开关 + 一键重载 + 作者信息 + 闲鱼链接（系统浏览器打开）

许可证：完全自主开发，适用仓库根目录 CC BY-NC 4.0 许可证，见 [LICENSE](LICENSE)。

### grenade_helper.lua — 道具点位助手

由 [AMWRV6 - Grenade Helper](https://github.com/Anybody4506/AMWRV6/blob/main/Grenade%20Helper) 移植、修复并改动而来（原作基于 Aimware 平台）。

- **回放执行**：按住执行按键自动瞄准点位视角并投掷（站投 / 跳投 / 走投 / 蹲投 / 宏点位），支持左键/双键/右键投掷模式
- **自动寻路**：寻路/停脚/投掷时序已对齐原版 AW 实现，自动走到最近点位并停稳执行
- **世界标签**：3D 点位名称 + 距离显示、点位圆环、FOV 范围圆环、回放状态显示、待机/就绪双色瞄准点
- **录制**：绑键式宏录制（逐帧 usercmd 回放，自动跳过前导静止段）、手动创建点位（跳投/走投方向与时长/投掷模式）
- **点位管理（右侧独立分组）**：地图选择 + 道具分类筛选 + **点位名称搜索**，滚轮翻页，行内改名与删除（直接写回数据文件）
- **状态组（右列点位管理下方）**：Allow Insecure 开关 + 一键重载 + 作者信息 + 闲鱼链接（系统浏览器打开）
- **数据文件**：`helper_data.txt` 存放点位（de_dust2 / de_mirage / de_nuke 等），改名/删除/新增均保留原格式

### FortniteDamage.lua — 堡垒之夜伤害数字

原作者 **1-star**，汉化 + 资源内嵌整合。

- **单文件**：190 张伤害数字贴图已内嵌进脚本（base64 + RLE 压缩），**无需再放 images 资源包**
- 爆头/身体/护甲伤害数字，支持独立颜色、缩放、显示时长、垂直偏移
- 四种动画样式：经典堡垒之夜 / 弹跳 / 漂浮 / 分裂
- 按目标过滤：自己 / 队友 / 敌人
- 内置状态组：Allow Insecure 开关 + 一键重载 + 作者信息 + 闲鱼链接（系统浏览器打开）

许可证：整合版本适用仓库根目录 CC BY-NC 4.0 许可证；原作权利归 1-star。

### MC Cheat HUD.lua — Minecraft 风格 HUD

移植自 Neverlose（CSGO）平台的同名脚本，全中文界面：

- **按键显示**：Minecraft 风格 WASD / 空格 / 鼠标按键块 + 左右键 CPS 计数，按下高亮颜色自定义，带按下/松开过渡动画，四组模块可单独隐藏
- **武器状态面板**：主武器 → 手枪 → 匕首 → 电击枪排序显示，弹药数字滚动动画，底部道具栏（手雷/烟雾/闪光/燃烧瓶/诱饵/拆弹钳/C4），使用**游戏内置武器图标**（未收录武器自动回退中文名）
- **外观自定义**：投影颜色 / 面板遮罩颜色 / 毛玻璃开关 / 武器图标颜色 / 武器文字颜色
- **缩放与透明度**：按键组与武器面板独立缩放（0.5-2.0）与不透明度（20-100%）
- **可拖拽**：菜单打开时直接拖动面板，位置持久保存
- **游戏 HUD 隐藏**：隐藏原版武器栏 / 底部血量弹药状态条（Panorama 实现，卸载自动还原）
- **零依赖**：无需 Allow Insecure、无需任何资源文件，单文件即用

许可证：移植版适用仓库根目录 CC BY-NC 4.0 许可证。鸣谢：小凤梨1337。

最近更新：修复按下按键时颜色高频闪烁的问题（按住常亮）；底部道具栏固定顺序（燃烧瓶 → 烟雾 → 诱饵 → 闪光 → 手雷 → 探测手雷 → 雪球 → C4 → 拆弹钳）。

### Angel Misc.lua — 天使光环 / 移动拖尾 / 挂机防踢

移植自 Neverlose CSGO 脚本 **XFL.Misc V4.7.4**，侧边栏改名 Angel Misc，全中文界面：

- **天使光环**：三种样式（华丽 / 简约 / 文字），支持圆形光环、渐变呼吸、旋转星光、圣光粒子、流动文字环、背面遮挡检测
- **移动拖尾**：多色轨迹、弹性动画、光晕效果，支持分段渐隐、颜色随机
- **挂机防踢**：自动徘徊，支持定时随机移动、移动方向随机、移动时长随机，玩家手动移动时自动停止
- **状态组**：Allow Insecure 开关 + 一键重载 + 作者信息 + 闲鱼链接（系统浏览器打开）

许可证：移植版适用仓库根目录 CC BY-NC 4.0 许可证。原作权利归 XFL.Misc 原作者。鸣谢：小凤梨1337。

### Solace Legit.lua — Solace legit 模块移植（通用配置，无武器分类）

移植自 Solace.dll 的 legit 模块分析还原，全中文界面，流水线对齐原版（自瞄 → 扳机 → 探头 → 移动）：

- **自瞄**：FOV、平滑、按距离调节、命中部位多选（头/胸/腹/臂/腿）、反应时间区间随机、最小伤害（可视 + 穿墙双门槛，原生 `trace.bullet` 判定）、自动开火 + 命中率门槛、仅站立开火、烟雾检查、FOV 圈 + 锁定目标可视化
- **人性化瞄准**：弧线瞄准路径（接近目标时自动收直）、弧线随机化、yaw/pitch 抖动、速度变化、轴速度噪声、总强度系数
- **后坐力控制**：`old_punch` 差值法、强度、每发 min/max 随机（避免恒定补偿被统计识别）、独立模式、仅全自动武器
- **自动扳机**：开火延迟、命中率门槛、仅爆头、最小伤害（含穿墙）、烟雾/闪光检查、开火前急停
- **自动急停**：开火前 / 瞄准时 / 始终 三模式 + 提前急停
- **特殊武器**：狙击自动开镜、R8 快速扣放扳机、Zeus 近距离自动开火、自动刀（背刺判定）
- **快速探头**：按住探出 → 急停停稳后开火 → 回撤（松开回撤 / 开火后回撤 两模式）、起点标记、探头辅助（按住平滑跟枪）
- **状态组**：Allow Insecure 开关 + 一键重载 + 作者信息 + 闲鱼链接（系统浏览器打开）

跳过项（Solace 报告建议或 CS2 限制）：silent aim（VAC 服校验 usercmd 角度）、backtrack（CS2 服务端不允许）、no spread 种子修正（高风险）。

许可证：移植版适用仓库根目录 CC BY-NC 4.0 许可证。原作权利归 Solace 原作者。

### spammer.lua — 自动刷屏整合

刷屏功能合集，每个刷屏功能独立拥有：启用开关 / 发送频道（公屏 say / 队伍 say_team）/ 发送间隔（0.1-10 秒）/ 随机顺序 / 控制台发送记录：

- **内置文案池**：辱骂台独（5 条）、中二刷屏（24 条）、嘴臭刷屏（80 条）、辱骂绿玩（26 条）
- **自定义刷屏**：三个自定义消息池（A/B/C，英文逗号分隔），随机模式一轮发完才重新洗牌（不重复），池内容修改后自动重置进度（整合自 zdmar.lua）
- **状态组**（移植自道具助手）：Allow Insecure 开关 + 一键重载 + 闲鱼链接

许可证：适用仓库根目录 CC BY-NC 4.0 许可证，见 [LICENSE](LICENSE)。

## 配套组件

### neverlose_core_newad_ffi.dll

脚本运行所需的 FFI 支持库，放置到 Neverwin 安装目录（通常为 `C:\neverwin\`）。

## 安装

1. 将需要的 `.lua` 脚本放入 `C:\neverwin\scripts\`
2. `helper_data.txt` 放入 `C:\neverwin\scripts\data\`（仅 grenade_helper 需要）
3. 在 Neverwin 脚本列表中启用，并勾选 **Allow Insecure**（MC Cheat HUD 无需勾选）
